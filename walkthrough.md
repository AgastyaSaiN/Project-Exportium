# Exportium - User Guide

## Welcome to Exportium
Exportium is your offline vault for social media memories. This guide helps you install and use the application.

## 📥 Installation

1.  **Download**: Get the latest installer (`Exportium Setup 0.0.5.exe`) from the [Release Page](https://github.com/AgastyaSaiN/Project-Exportium/releases/latest).
2.  **Install**: Double-click the `.exe`. It will seamlessly install to your User folder.
3.  **Launch**: Open "Exportium" from your Start Menu or Desktop.

## 🚀 How to Use

### 1. The Dashboard
When you open the app, you see the "Privacy Grid".
- **Supported Apps**: Instagram, Telegram, WhatsApp, Discord, etc.
- **Connection**: Since this is "Offline Only", you do not "login". Instead, you import data files.

### 2. Importing Data
*(Not yet implemented in v0.0.5 UI, coming in v0.1.0)*
- Click on an app icon (e.g., "Instagram").
- Drag and drop your `.zip` or `.json` export file into the drop zone.
- Exportium parses the file instantly.

### 3. Browsing
- Click "View Archives" to see your chats.
- Use the Search Bar to find specific messages across years of history.

## 🛠 Troubleshooting

**"Windows protected your PC"**
Since we are an open-source project, we don't buy expensive certificates yet.
- Click **"More Info"**.
- Click **"Run Anyway"**.

**"Data not loading"**
- Ensure you exported the data in **JSON** format (not HTML) from Instagram/Telegram.
