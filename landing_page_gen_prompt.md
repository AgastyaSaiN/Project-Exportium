# Prompt: Build the Ultimate Landing Page for Exportium

**Role**: You are an award-winning UI/UX Designer and Senior Frontend Engineer specializing in high-conversion SaaS landing pages.

**Objective**: Design and Implement a stunning, single-page landing site for a new Desktop Application called **"Exportium"**.

**Product Context**:
- **What is it?**: A privacy-first Desktop Application (Windows) that lets users visualize their social media data exports (Instagram, WhatsApp, Telegram, etc.) securely and offline.
- **Key Selling Points**:
    1.  **100% Offline & Private**: Data never leaves the user's device.
    2.  **Universal Import**: Supports multiple platforms (Insta, TG, etc.).
    3.  **Beautiful Visualization**: Turns raw JSON exports into a searchable, readable chat interface.
- **Target Audience**: Privacy-conscious users, data hoarders, and people who want to browse old memories without being online.

**Design Aesthetic (Critical)**:
- **Theme**: Premium Dark Mode.
- **Palette**: `Slate-900` (Background), `Slate-800` (Cards), `White` (Text), with glowing accents of `Electric Blue` or `Amber` (for the "Privacy" feel).
- **Style**: Glassmorphism (subtle blurs), modern typography (Inter/Geist Sans), and micro-interactions (hover glows).
- **Vibe**: "Trustworthy", "Fast", "Modern".

**Technical Stack**:
- **Framework**: React (Vite) or Next.js.
- **Styling**: Tailwind CSS (Mandatory).
- **Animation**: Framer Motion (for smooth fade-ins and button interactions).
- **Icons**: Lucide React.

**Page Structure (Section by Section)**:

1.  **Navbar**:
    - Logo (Left): "Exportium" (Icon + Text).
    - Links (Right): Features, Security, GitHub (Icon).
    - CTA Button (Far Right): "Download v0.0.5" (Small, secondary style).

2.  **Hero Section (The "Hook")**:
    - **Headline**: "Your Digital Life, Reimagined Offline."
    - **Subheadline**: "Visualize your social media archives securely on your desktop. No cloud, no tracking, just your memories."
    - **Primary CTA**: A massive, glowing button: **"Download for Windows"** (Text below: *v0.0.5 • Free & Open Source*).
    - **Visual**: A tilted, floating 3D-style screenshot of the App Interface (Glass effect) on the right side.

3.  **The "Trust" Grid (Features)**:
    - Three large cards with icons:
        - **🔒 Privacy First**: "Runs 100% offline. We never see your data."
        - **⚡ Lightning Fast**: "Instant search through years of chat history."
        - **📂 Universal Support**: "Instagram, Telegram, WhatsApp supported out of the box."

4.  **"How it Works" (Step-by-Step)**:
    - 1. Request your data export (e.g., from Instagram).
    - 2. Drag & Drop the ZIP file into Exportium.
    - 3. Browse your memories instantly.

5.  **Open Source / Trust Section**:
    - "Built with transparency."
    - Link to GitHub Repository.
    - Mention the tech stack (Electron, React, TypeScript).

6.  **Footer**:
    - Copyright 2024.
    - Links to Privacy Policy (Simple text).
    - Social links.

**Instructions for Output**:
- Provide the **Complete functionality** in a single React file (or breakdown if large).
- Use `framer-motion` for entrance animations.
- Ensure the "Download" button links to: `https://github.com/AgastyaSaiN/Project-Exportium/releases/download/v0.0.5/Exportium-Setup-0.0.5.exe`
- **Do not use placeholders**. Write actual, compelling marketing copy.

**GO.**
